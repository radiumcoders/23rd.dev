## Usage

Give the parent a size; the machine scales to fit.

<FrameworkCode>
  <FrameworkReact>
```tsx
"use client"

import { Typewriter } from "@/components/ui/typewriter"

export function Letter() {
  return (
    <div className="h-96 w-full overflow-hidden rounded-xl border">
      <Typewriter text={"Dear reader,\nthe ribbon is fresh."} />
    </div>
  )
}
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<script>
  import Typewriter from "$lib/components/ui/typewriter.svelte"
</script>

<div class="h-96 w-full overflow-hidden rounded-xl border">
  <Typewriter text={"Dear reader,\nthe ribbon is fresh."} />
</div>
```
  </FrameworkSvelte>
</FrameworkCode>

`\n` breaks a line; text wraps at `columns` characters.

<FrameworkCode>
  <FrameworkReact>
    ```tsx
    <Typewriter loop={false} onDone={() => console.log("typed")} />
    <Typewriter color="#D2463A" speed={8} columns={40} sound />
    ```
  </FrameworkReact>
  <FrameworkSvelte>
    ```svelte
    <Typewriter loop={false} onDone={() => console.log("typed")} />
    <Typewriter color="#D2463A" speed={8} columns={40} sound />
    ```
  </FrameworkSvelte>
</FrameworkCode>

`sound` only plays after the visitor has clicked or pressed a key on the page.

## Props

| Prop         | Type         | Default                                             |
| ------------ | ------------ | --------------------------------------------------- |
| `color`      | `string`     | `"#8EC3B5"`, body enamel |
| `text`       | `string`     | a short letter |
| `speed`      | `number`     | `12`, characters per second |
| `humanize`   | `boolean`    | `true`, uneven rhythm |
| `jitter`     | `number`     | `0.3`, 0–1 |
| `columns`    | `number`     | `32`, 16–60 |
| `loop`       | `boolean`    | `true` |
| `hold`       | `number`     | `2600`, ms before looping |
| `startDelay` | `number`     | `600`, ms |
| `sound`      | `boolean`    | `false` |
| `interactive` | `boolean`   | `true` |
| `label`      | `string`     | none, nameplate text |
| `onDone`     | `() => void` | fires when the last character lands |
| `className`  | `string`     | React only                                          |
| `class`      | `string`     | Svelte only                                         |
