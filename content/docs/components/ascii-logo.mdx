## Usage

Give the parent a size; the canvas fills it.

<FrameworkCode>
  <FrameworkReact>
```tsx
"use client"

import { AsciiLogo } from "@/components/ui/ascii-logo"

export function FooterMark() {
  return (
    <div className="relative h-64 w-full overflow-hidden bg-background">
      <AsciiLogo text="23rd" />
    </div>
  )
}
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<script>
  import AsciiLogo from "$lib/components/ui/ascii-logo.svelte"
</script>

<div class="relative h-64 w-full overflow-hidden bg-background">
  <AsciiLogo text="23rd" />
</div>
```
  </FrameworkSvelte>
</FrameworkCode>

`text` takes up to 5 letters. Pass `src` to sample an image instead (any raster, or a same-origin SVG).

<FrameworkCode>
  <FrameworkReact>
```tsx
<AsciiLogo src="/logo-mark.png" />
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<AsciiLogo src="/logo-mark.png" />
```
  </FrameworkSvelte>
</FrameworkCode>

Clicks cycle `logo → scattered → fallen → returning → logo`.

## Props

| Prop              | Type                          | Default                         |
| ----------------- | ----------------------------- | ------------------------------- |
| `text`            | `string`                      | `"23rd"` (max 5 letters)        |
| `src`             | `string`                      | none                               |
| `fit`             | `number`                      | `0.82`                          |
| `cellSize`        | `number`                      | `11`                            |
| `cellGap`         | `number`                      | `2`                             |
| `charset`         | `string`                      | letters, numbers, a few symbols |
| `threshold`       | `number`                      | `0.2`                           |
| `invert`          | `boolean`                     | `true` when `src` is set        |
| `color`           | `string`                      | theme ink                       |
| `backgroundColor` | `string`                      | theme paper                     |
| `hoverRadius`     | `number`                      | `7`                             |
| `hoverPush`       | `number`                      | `2.6`                           |
| `hoverEase`       | `number`                      | `0.18`                          |
| `scatterRange`    | `number`                      | `16`                            |
| `scatterEase`     | `number`                      | `0.055`                         |
| `gravity`         | `number`                      | `0.14`                          |
| `bounce`          | `number`                      | `0.28`                          |
| `resetEase`       | `number`                      | `0.08`                          |
| `staggerFrames`   | `number`                      | `18`                            |
| `interactive`     | `boolean`                     | `true`                          |
| `theme`           | `"light" \| "dark" \| "auto"` | `auto`                          |
| `label`           | `string`                      | `text` or `"ASCII logo"`        |
| `onPhaseChange`   | `(phase) => void`             | none                               |
| `className`       | `string`                      | React only                      |
| `class`           | `string`                      | Svelte only                     |
