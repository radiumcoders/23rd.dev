## Usage

<FrameworkCode>
  <FrameworkReact>
```tsx
import { GooeyColorPicker } from "@/components/ui/gooey-color-picker"

export function Example() {
  return (
    <GooeyColorPicker
      defaultValue={{ h: 210, s: 90, l: 55, a: 1 }}
      onChange={(color, css) => {
        console.log(color, css)
      }}
    />
  )
}
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte

  import GooeyColorPicker from "$lib/components/ui/gooey-color-picker.svelte"
</script>

  }}
/>
```
  </FrameworkSvelte>
</FrameworkCode>

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `GooeyColor \| string` | none |
| `defaultValue` | `GooeyColor \| string` | `{ h: 320, s: 90, l: 58, a: 1 }` |
| `onChange` | `(color: GooeyColor, css: string) => void` | none |
| `label` | `string` | `"Color picker"` |
| `className` | `string` | React only |
| `class` | `string` | Svelte only |

`GooeyColor` is `{ h, s, l, a }` (h 0–360, s and l 0–100, a 0–1); strings accept hex or `hsl`/`hsla`.
