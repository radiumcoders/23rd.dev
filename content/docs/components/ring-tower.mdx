## Usage

Pin it inside a relatively positioned section with a height. The canvas is transparent, so give the section a background. The inside of the bands fades toward black in dark mode and white in light mode, following the page unless you set `theme`. Each band leans a quarter turn from the last, so the stack zig-zags past the edges of the frame.

Images are drawn side by side at one height and repeated in whole tiles around each band, then cropped top and bottom to keep their proportions. Images on another origin need CORS headers, or they are skipped. With no images, or if none load, the bands show a plain green grid.

### Each ring

Pass `rings` an array instead of a number to set each ring on its own, bottom ring first. The array's length is the ring count, up to 5. Anything a ring leaves out follows the tower, so `{}` is a plain ring.

<FrameworkCode>
  <FrameworkReact>
```tsx
<RingTower
  images={bands}
  rings={[
    {},
    { tilt: -20, spin: 30 },
    { rotation: 45, speed: -1.5, images: ["/bands/feature.jpg"] },
  ]}
/>
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<RingTower
  images={bands}
  rings={[
    {},
    { tilt: -20, spin: 30 },
    { rotation: 45, speed: -1.5, images: ["/bands/feature.jpg"] },
  ]}
/>
```
  </FrameworkSvelte>
</FrameworkCode>

| Ring field | Type | Default |
| --- | --- | --- |
| `rotation` | `number` | `i * 90`, degrees; which way the ring leans |
| `tilt` | `number` | `14`, degrees, −45–45 |
| `spin` | `number` | `0`, degrees per second, −180–180; sweeps the lean around |
| `speed` | `number` | the tower's `speed`, −4–4; negative crawls backwards |
| `parallax` | `number` | the tower's `parallax`, alternating direction; degrees, −90–90 |
| `images` | `string[]` | the tower's `images` |

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `images` | `string[]` | none, draws a grid band |
| `rings` | `number \| RingTowerRing[]` | `5`, 1–5, or one object per ring |
| `speed` | `number` | `1`, 0–4 crawl speed |
| `draggable` | `boolean` | `true` |
| `parallax` | `number` | `24`, degrees, 0–90 |
| `backface` | `number` | `0.86`, inside fade, 0–1 |
| `theme` | `"light" \| "dark" \| "auto"` | `auto` |
| `className` | `string` | React only |
| `class` | `string` | Svelte only |
