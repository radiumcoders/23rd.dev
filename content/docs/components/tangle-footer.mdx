A few vines run the width of the footer, curling into round loops off a wandering baseline and relaxing into waves between them. Where lines cross, the one on top clears a hairline gap around itself, so every crossing reads as over or under — including loops crossing themselves. It's transparent and drawn in the text color, so it sits on any page and follows light and dark. The vines grow in once, the first time the footer is seen, then hold still. Change **Seed** for a new tangle.

## Usage

Put it at the bottom of the page. It fills the width it's given, `height` px tall, in the current text color — set `className="text-muted-foreground"` (or `color`) to change it.

<FrameworkCode>
  <FrameworkReact>
```tsx
import { TangleFooter } from "@/components/ui/tangle-footer"

export function SiteFooter() {
  return <TangleFooter className="text-foreground" />
}
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<script>
  import TangleFooter from "$lib/components/ui/tangle-footer.svelte"
</script>

<TangleFooter class="text-foreground" />
```
  </FrameworkSvelte>
</FrameworkCode>

## Props

| Prop        | Type     | Default                                       |
| ----------- | -------- | --------------------------------------------- |
| `height`    | `number` | `320` — px                                    |
| `vines`     | `number` | `3` — `1`–`12`                                |
| `thickness` | `number` | scales with width — line width in px          |
| `color`     | `string` | `currentColor`                                |
| `seed`      | `number` | `23` — a new seed grows a new tangle          |
| `className` | `string` | React only                                    |
| `class`     | `string` | Svelte only                                   |

`prefers-reduced-motion: reduce` skips the grow-in and shows the finished tangle.
