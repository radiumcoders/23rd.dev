## Usage

```tsx
"use client"

import { LiveOrb } from "@/components/ui/live-orb"

export function Mascot() {
  return <LiveOrb />
}
```

Without a `variant` the orb is white on dark pages and black on light ones. `custom` uses `color` and `eyeColor`; `webgl` takes an optional three-stop `colors`.

```tsx
<LiveOrb variant="white" />
<LiveOrb variant="black" />
<LiveOrb variant="webgl" />
<LiveOrb variant="webgl" colors={["#7C6AF7", "#7DD3C7", "#E8B4D4"]} />
<LiveOrb variant="custom" color="#7C5CFF" eyeColor="#FAFAFA" />
```

## Props

| Prop          | Type                                        | Default                   |
| ------------- | ------------------------------------------- | ------------------------- |
| `variant`     | `"white" \| "black" \| "webgl" \| "custom"` | follows theme             |
| `size`        | `number`                                    | `280`                     |
| `color`       | `string`                                    | `"#7C5CFF"`               |
| `eyeColor`    | `string`                                    | `"#FAFAFA"`               |
| `colors`      | `string[]`                                  | violet / foam / dust-rose |
| `interactive` | `boolean`                                   | `true`                    |
| `blink`       | `boolean`                                   | `true`                    |
| `theme`       | `"light" \| "dark" \| "auto"`               | `"auto"`                  |
| `className`   | `string`                                    | none                      |
