## Usage

<FrameworkCode>
  <FrameworkReact>
```tsx
"use client"

import { LiveOrb } from "@/components/ui/live-orb"

export function Mascot() {
  return <LiveOrb />
}
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<script>
  import LiveOrb from "$lib/components/ui/live-orb.svelte"
</script>

<LiveOrb />
```
  </FrameworkSvelte>
</FrameworkCode>

`custom` uses `color` and `eyeColor`; `webgl` takes an optional three-stop `colors`.

<FrameworkCode>
  <FrameworkReact>
```tsx
<LiveOrb variant="white" />
<LiveOrb variant="black" />
<LiveOrb variant="webgl" />
<LiveOrb variant="webgl" colors={["#7C6AF7", "#7DD3C7", "#E8B4D4"]} />
<LiveOrb variant="custom" color="#7C5CFF" eyeColor="#FAFAFA" />
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<LiveOrb variant="white" />
<LiveOrb variant="black" />
<LiveOrb variant="webgl" />
<LiveOrb variant="webgl" colors={["#7C6AF7", "#7DD3C7", "#E8B4D4"]} />
<LiveOrb variant="custom" color="#7C5CFF" eyeColor="#FAFAFA" />
```
  </FrameworkSvelte>
</FrameworkCode>

## Props

| Prop          | Type                                        | Default                   |
| ------------- | ------------------------------------------- | ------------------------- |
| `variant`     | `"white" \| "black" \| "webgl" \| "custom"` | `"white"`                 |
| `size`        | `number`                                    | `280`                     |
| `color`       | `string`                                    | `"#7C5CFF"`               |
| `eyeColor`    | `string`                                    | `"#FAFAFA"`               |
| `colors`      | `string[]`                                  | violet / foam / dust-rose |
| `interactive` | `boolean`                                   | `true`                    |
| `blink`       | `boolean`                                   | `true`                    |
| `className`   | `string`                                    | React only                |
| `class`       | `string`                                    | Svelte only               |
