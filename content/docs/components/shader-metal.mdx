Polished metal ribbons that twist and flow across a hero. Each ribbon is a curved, brushed strip that reflects a whole studio (an overhead softbox, warm and cool strip lights, and a crisp horizon), so it reads as real metal, not a gradient. Light mode lights it like a bright product shoot; dark mode puts it on a black stage where only the highlights catch. Move the pointer and the key light follows it while the ribbons lean in. Pick **chrome**, **gold**, **copper**, or **graphite**, or tint your own with `color`; `iridescence` adds a thin-film sheen on the turns. The canvas is transparent, so the ribbons and their soft shadows sit on whatever background you give them.

## Usage

Pin it behind a relatively positioned section. Keep content in a later stacking context (`relative z-10`). The ribbons sweep corner to corner through the middle, so copy sits best top-left. Default `theme="auto"` follows shadcn / next-themes (`class` on `<html>`).

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `metal` | `"chrome" \| "gold" \| "copper" \| "graphite"` | `chrome` |
| `color` | `string` | hex tint; wins over `metal` |
| `ribbons` | `number` | `3`, 1–5 |
| `speed` | `number` | `0.3` |
| `iridescence` | `number` | `0.2`, 0–1 thin-film sheen, `0` for bare metal |
| `interactive` | `boolean` | `true`, key light follows the pointer, ribbons lean in |
| `theme` | `"light" \| "dark" \| "auto"` | `auto` |
| `className` | `string` | React only |
| `class` | `string` | Svelte only |
