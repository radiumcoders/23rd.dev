import { AsciiFluidDemo } from "@/registry/ascii-fluid/ascii-fluid-demo"

Pointer trails dump ink into a fluid sim; density maps onto a full letter/symbol brightness ramp. Theme-aware. No text input — just a background. Press `d` to toggle theme.

## Usage

Place it behind content in a relatively positioned container.

<FrameworkCode>
  <FrameworkReact>
```tsx
"use client"

import { AsciiFluid } from "@/components/ui/ascii-fluid"

export function Hero() {
  return (
    <div className="relative h-svh overflow-hidden bg-background">
      <AsciiFluid />
      <div className="relative z-10 p-10">Your content</div>
    </div>
  )
}
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<script>
  import AsciiFluid from "$lib/components/ui/ascii-fluid.svelte"
</script>

<div class="relative h-svh overflow-hidden bg-background">
  <AsciiFluid />
  <div class="relative z-10 p-10">Your content</div>

```
  </FrameworkSvelte>
</FrameworkCode>

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `charset` | `string` | full letter/symbol brightness ramp |
| `cellSize` | `number` | `12` |
| `color` | `string` | theme ink |
| `backgroundColor` | `string` | theme paper |
| `force` | `number` | `1` |
| `dissipation` | `number` | `0.05` |
| `brush` | `number` | `0.55` |
| `animate` | `boolean` | `true` |
| `interactive` | `boolean` | `true` |
| `theme` | `"light" \| "dark" \| "auto"` | `auto` |
| `className` | `string` | React only |
| `class` | `string` | Svelte only |
