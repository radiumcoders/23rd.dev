23rd is a [shadcn/ui](https://ui.shadcn.com) registry for React and Svelte 5. Pick your framework on the install command.

## Install a component

<CliCommand item="shader-gradient" />

Or from the public GitHub registry:

<CliCommand item="shader-gradient" github />

Swap `shader-gradient` for any item name. Svelte items are `@23rd/<name>-svelte` and land in `src/lib/components/ui/`.

## Use a background or shader

Put it in a relatively positioned container, with your content in a later stacking context.

<FrameworkCode>
  <FrameworkReact>
```tsx
"use client"

import { ShaderGradient } from "@/components/ui/shader-gradient"

export function Hero() {
  return (
    <section className="relative isolate min-h-svh overflow-hidden bg-background">
      <ShaderGradient />
      <div className="relative z-10 p-10">Your content</div>
    </section>
  )
}
```
  </FrameworkReact>
  <FrameworkSvelte>
```svelte
<script>
  import ShaderGradient from "$lib/components/ui/shader-gradient.svelte"
</script>

<section class="relative isolate min-h-svh overflow-hidden bg-background">
  <ShaderGradient />
  <div class="relative z-10 p-10">Your content</div>
</section>
```
  </FrameworkSvelte>
</FrameworkCode>
