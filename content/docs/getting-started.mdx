23rd is a [shadcn/ui](https://ui.shadcn.com) registry. After install you own the source — same as any other registry item.

## Install a component

<CliCommand command="shadcn@latest add @23rd/dither" />

Or pull straight from the public GitHub source registry:

<CliCommand
  npm="npx shadcn@latest add radiumcoders/23rd.dev/dither"
  pnpm="pnpm dlx shadcn@latest add radiumcoders/23rd.dev/dither"
  yarn="yarn dlx shadcn@latest add radiumcoders/23rd.dev/dither"
  bun="bunx --bun shadcn@latest add radiumcoders/23rd.dev/dither"
/>

Swap `dither` for any item name — `shader-gradient`, `tangle-footer`, `gooey-color-picker`, and so on.

## Use a background

Place the component behind content in a relatively positioned container. Keep the UI in a later stacking context.

```tsx
"use client"

import { Dither } from "@/components/ui/dither"

export function Hero() {
  return (
    <section className="relative isolate min-h-svh overflow-hidden bg-background">
      <Dither variant="wind" />
      <div className="relative z-10 p-10">Your content</div>
    </section>
  )
}
```

Shaders such as [Shader Gradient](/docs/components/shader-gradient) follow the same pattern — they are atmosphere, not the page.
