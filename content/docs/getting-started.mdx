23rd is a [shadcn/ui](https://ui.shadcn.com) registry. After install you own the source — same as any other registry item.

## Install a component

<CliCommand command="shadcn@latest add @23rd/shader-gradient" />

Or pull straight from the public GitHub source registry:

<CliCommand
  npm="npx shadcn@latest add radiumcoders/23rd.dev/shader-gradient"
  pnpm="pnpm dlx shadcn@latest add radiumcoders/23rd.dev/shader-gradient"
  yarn="yarn dlx shadcn@latest add radiumcoders/23rd.dev/shader-gradient"
  bun="bunx --bun shadcn@latest add radiumcoders/23rd.dev/shader-gradient"
/>

Swap `shader-gradient` for any item name — `shader-fire`, `live-orb`, `ascii-logo`, `radiant-lines`, `dithered-404`, `tangle-footer`, and so on.

## Use a background or shader

Place the component behind content in a relatively positioned container. Keep the UI in a later stacking context.

```tsx
"use client"

import { ShaderGradient } from "@/components/ui/shader-gradient"

export function Hero() {
  return (
    <section className="relative isolate min-h-svh overflow-hidden bg-background">
      <ShaderGradient />
      <div className="relative z-10 p-10">Your content</div>
    </section>
  )
}
```

Shaders such as [Shader Gradient](/docs/components/shader-gradient) and [Shader Fire](/docs/components/shader-fire) are atmosphere, not the page.
