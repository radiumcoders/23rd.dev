# Sticker Peel (reference only)

Local copy of [React Bits Sticker Peel](https://reactbits.dev/animations/sticker-peel), JavaScript + CSS variant. It is here as inspiration for Image Peel. It is not a 23rd registry item and it is not imported by the docs app.

The React Bits sticker peels on hover and drag. Image Peel peels on scroll, from a corner, with a white back and no shadow behind the sheet.

Needs `gsap`, including `Draggable`.
